# The Vault Render Optimization 0.3.3

Release date: August 3, 2026

VRO 0.3.3 is a focused stability patch for the optional dynamic-light engine
introduced in 0.3.2. No existing optimization, default, command, or
compatibility target was removed or otherwise changed.

## Download

Install the runnable artifact:

```text
vault_render_optimization.0.3.3.jar
```

Stop Minecraft and keep only one active VRO JAR. No server installation, world
migration, configuration reset, or cache deletion is required.

## Fixed

### Block-entity ticker crash

VRO's block-entity dynamic-light observer previously iterated Minecraft's live
block-entity ticker list directly. A block entity being added or removed during
that scan invalidated the iterator and could crash the render thread with a
`ConcurrentModificationException`.

The observer also entered that list while VRO dynamic lighting was disabled.
This meant the crash could occur on clients using another dynamic-light
provider, even though VRO's own dynamic-light master switch was off.

VRO 0.3.3 corrects both paths:

- The observer returns before touching the ticker list unless VRO dynamic
  lighting and block-entity sources are both active.
- When deliberately enabled, block entities are observed from a stable
  per-tick snapshot so structural changes cannot invalidate iteration.

Held-item lighting supplied by another mod, such as Embeddium++, remains
independent and is not changed by this patch.

## Validation

- Reproduced and matched two client crash reports from VRO 0.3.2.
- Confirmed both reports failed in `LevelDynamicLightMixin` with the same
  render-thread `ConcurrentModificationException`.
- Compiled the final source against official Third Edition, Remastered, Wolds,
  and the selected custom Vault Hunters baselines.
- Tested the corrected build in the affected VaultCrafters client.
- Verified the retained release JAR matches the build output.
