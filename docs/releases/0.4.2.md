# The Vault Render Optimization 0.4.2

VRO 0.4.2 reduces the cost of Sophisticated Storage barrel displays in large
storage rooms while preserving their normal visible contents. This remains a
client-only Minecraft 1.18.2 Forge update; servers and worlds do not need any
changes.

## Sophisticated Storage barrel displays

- Skips item, quantity, fill-level, and upgrade rendering when the barrel's
  front faces away from the camera or is directly covered by another block.
- Reuses a bounded cache of quantity glyphs instead of rebuilding the same
  number geometry across many displays.
- Emits fill-level bars without the legacy per-vertex temporary vector
  allocations.
- Prevents count- and fill-only client updates from requesting an unnecessary
  chunk-model rebuild. Updates that can affect the model still rebuild normally.
- Leaves tier badges and their rendering unchanged.

The implementation is enabled only for the bytecode-validated pair used by
Vault Hunters Remastered: Sophisticated Storage `1.18.2-0.9.8.915` and
Sophisticated Core `1.18.2-0.6.4.604`. Unknown layouts fail closed and retain
the original mod behavior.

## Controls and defaults

All four storage paths are enabled by default and can be changed without a
client restart. `/vro storage` reports selection, rendered and culled faces,
quantity-cache activity, fill-bar work, allowed model rebuilds, and skipped
count-only rebuilds. Compare Mode temporarily yields the performance paths for
side-by-side testing.

## Fix included before release

Release validation found and corrected limited-barrel fill texture coordinates,
including the small multi-slot fill column. The public 0.4.2 build contains the
corrected rendering.

## Installation

Stop Minecraft, replace the older VRO jar with
`vault_render_optimization.0.4.2.jar`, and keep only one VRO version in the
instance's `mods` folder. No configuration reset, world migration, cache
deletion, or server installation is required.
